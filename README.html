The Origin Story

Built from real struggle.
Not from theory.

LENS wasn't designed in a boardroom. It was born from a personal transformation — and a desperate need for a tool that actually matched the journey.

For years, I lived in what I now call the loop — waking up every day, working hard, spending everything, and going to sleep knowing nothing had actually changed. No direction. No habits. No system. Just noise masquerading as life.

Then one day, a video on YouTube made me stop and think. The content itself wasn't revolutionary — but something clicked. I realized that if things stayed the way they were, they weren't going to lead anywhere. So I decided to change.

I started studying neuroscience, building habits, learning about dopamine and discipline. I finished my high school diploma I'd been putting off for years. I built a body, a mindset, and eventually — a new identity.

LENS is the tool I wish I had when I started. Every feature in this app maps directly to something that changed my life: habit tracking, focus sessions, gamification that rewards consistency, and a community that holds you accountable.

Quick Start

Running in 5 minutes.

Clone, install and run. No complex configuration required.

1

Clone & Install

Clone the repository and install all dependencies.

git clone https://github.com/your-user/lens.git
cd lens
npm install
2

Configure Environment

Create a .env file with your database connection string from Neon or Supabase.

# .env
DATABASE_URL="your-postgresql-connection-string"
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="your-secret-key"
3

Setup Database

Generate the Prisma client, push the schema and seed initial data.

npx prisma generate
npx prisma db push
npx tsx prisma/seed.ts
4

Run & Explore

Start the development server and open localhost:3000/dashboard

npm run dev
